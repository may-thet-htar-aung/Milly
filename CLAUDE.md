# CLAUDE.md

Milly uses `AGENTS.md` as the canonical repository guidance for coding agents.

Read these files before making changes:

1. `SPEC.md` for product scope, feature focus, boundaries, and acceptance criteria.
2. `README.md` for repository setup and developer workflow.
3. `AGENTS.md` for contribution rules, security constraints, and validation commands.

Project-specific setup details are in `api/README.md` and `app/README.md`.

Do not duplicate or override the policy in `AGENTS.md`. If this file and `AGENTS.md` ever differ, follow `AGENTS.md` and update this compatibility file.
